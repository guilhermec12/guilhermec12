# Olá, sou Guilherme Correia

Estudante de Engenharia de Software, com interesse em programação e desenvolvimento de aplicações. Uso este espaço para reunir projetos da faculdade e acompanhar meu aprendizado na prática.

Nos meus projetos, trabalho com interfaces em HTML, CSS e JavaScript, exercícios em Python e experimentos com ESP32. Também exploro UX/UI, acessibilidade e a organização do código.

## Projetos em destaque

### [Pelé Academia — aplicação web](https://github.com/guilhermec12/pele-academia-sprint-3)

Projeto acadêmico com interface responsiva, filtros combinados, favoritos, votos e validação de formulários. Implementado com JavaScript nativo e persistência local para demonstração.

**Tecnologias:** HTML, CSS e JavaScript.

### [Monitoramento ambiental com ESP32](https://github.com/guilhermec12/eccs-edge-computing-treinos)

Simulação de leitura de temperatura e umidade, processamento local e exibição em display OLED. Integração com ThingSpeak para acompanhar os dados enviados pelo dispositivo.

**Tecnologias:** C++, ESP32, DHT22, Wokwi e ThingSpeak.

### [Dose+ — UX/UI e acessibilidade](https://github.com/guilhermec12/dose-mais-cp5)

Projeto acadêmico em colaboração com João Silva. Apresentação web com pesquisa de UX e protótipo para explorar uma rotina de medicamentos mais acessível para idosos e familiares.

**Tecnologias:** HTML, CSS e JavaScript. **Foco:** UX/UI, acessibilidade e prototipação.
